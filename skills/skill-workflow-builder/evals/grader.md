# 行為 grader

以案例的實際路由、規則增量與驗證證據評分，不要求固定文字。

每案 0–2 分：

- 2：選擇符合 `expected.decision` 的路由或允許範圍，處理所有必要語意，沒有建立多餘結構或把已成功 baseline 內容固化成規則。
- 1：路由正確，但漏掉一個必要限制、證據要求或相容性考量。
- 0：替一次性任務建立 Skill、遇到同用途 Skill 仍另建、以臆測取代 baseline，或把 baseline 已做好的日期行為新增成規則。

總分必須 8/8；前三個核心案例任何一案低於 2 都不通過。若回應宣稱 `quick_validate.py` 證明行為正確，整體直接不通過。
