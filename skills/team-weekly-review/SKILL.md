# 團隊週報

用可追溯證據整理團隊一週狀態。預設只在對話交付；除非使用者指定位置，不寫檔、不更新任務系統。

## 時間窗

- 未指定範圍：使用上一個完整 ISO week，按使用者或工作區的當地時區切分。
- 指定「本週」：從當週週一 00:00 到目前，明標為未完整週。
- 明確指定日期：依指定範圍，不自行補齊。

報告必須列起訖時間、時區與產出截止時間。

## 來源契約

必要來源是目前工作區的 git log、branch、HEAD 與未提交狀態。任務／工單系統、CI 與部署紀錄、daily log、
會議紀錄、handoff 或其他工作區都是可選來源。

每個來源標示 `available`、`degraded` 或 `unavailable`。缺少可選來源不等於 0 件工作，也不能推論沒有風險。
無法 fetch 時，只能描述本機 remote-tracking ref，不得宣稱遠端最新。

## 建立證據帳

| 主張 | 證據 | 時間 | 視角 | 狀態 |
| :-- | :-- | :-- | :-- | :-- |
| 候選週報句子 | commit／任務／CI／runtime／文件 | 來源時間 | workspace／local／remote／runtime | 已證實／有限／未知 |

- commit message、任務狀態與交接文件是線索，不單獨構成完成證據。
- shared history 與 branch-only commit 分開，避免重複計數。
- 同一事件被多份文件提到仍只算一次。
- 本機、遠端與 runtime 有差異時分開陳述，不收斂成單一版本。

## 分類

- **已交付**：只列有直接證據支持的成果；建立、驗證、發布不可混成同一狀態。
- **進行中**：列可觀察的下一步與 owner；沒有可靠 owner 時寫未知，不從 author 名稱猜人。
- **決策**：只列時間窗內新決定或目前仍影響工作的決策；舊 pending 必須重查。
- **風險與阻塞**：指出影響、現有證據，以及需要誰補什麼。
- **下週重點**：最多三件，必須可追溯到未完成承諾、既定目標或本週證據；依據不足就標待確認。

## 輸出格式

```markdown
# 團隊週報｜YYYY-Www

> 統計範圍、時區、截止時間、工作區與觀測視角

## 一眼摘要
## 已交付
## 進行中
## 本週決策
## 風險與阻塞
## 下週重點（最多三件）
## 證據與觀測盲區

### 來源狀態
| 來源 | 狀態 | 覆蓋範圍／限制 |
| :-- | :-- | :-- |
```

## 判讀限制

- commit 數是活動量，不是價值、生產力或成員績效。
- 沒有 log 只能說該時間看不到，不能說沒工作。
- 多個來源一致仍可能共用同一個錯誤前提；重要狀態要看產物或 runtime。
- 不寫入對話原文、憑證或不必要的個人資料。

## 寫檔規則

預設停在對話輸出。使用者明確指定儲存位置後，先確認既有檔案，不得無聲覆寫；寫入後回報實際路徑與驗證。

## 驗收標準

- 時間窗、時區、工作區與來源狀態完整。
- 可選來源缺失顯示 `unavailable`，沒有寫成 0。
- local、remote、runtime 分開描述。
- 完成主張附直接證據，舊 pending 經現況重查。
- 下週重點不超過三件且有依據。
- 未經指定沒有寫檔或更新外部系統。
